# Google Lens & Multisearch Optimization Strategy

This document outlines the visual matching, Google Lens, Pinterest Pin discovery, and multimodal visual search strategy for **WATCHWORLDCUP**.

## 1. Visual Matching for Sports Graphics

Mobile users scanning broadcast charts or sports emblems with **Google Lens** receive visual matching SERP cards linking directly to `watchworldcup.us`.

- **Visual Clarity**: High-contrast, 1200x630 graphics with crisp typography.
- **Embedded Metadata**: HTML `<figure>` and `<figcaption>` elements provide instant contextual weight to Lens crawlers.

## 2. Schema.org ImageObject Integration

The `<OptimizedImage />` component injects JSON-LD `ImageObject` markup on all visual landing pages, ensuring Google Lens connects visual elements with domain entity `WATCHWORLDCUP`.
