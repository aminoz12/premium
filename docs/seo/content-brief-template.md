# Content brief template

Complete this brief before a new indexable editorial or commercial page is created. A completed brief is an editorial record, not evidence by itself.

| Field | Required entry |
| --- | --- |
| Proposed URL and canonical | One normalized `https://watchworldcup.us` URL; state whether an existing page should be updated, merged or redirected instead. |
| Route class and indexability | Public editorial, public commercial, legal/trust, private/transactional or utility; explain why the page may be indexed. |
| User question and intent | The specific problem a visitor needs solved and the expected intent. |
| Direct answer | A concise, factual answer that will appear near the top of the page. |
| Primary topic and supporting questions | The main topic plus the questions, definitions, steps or comparison criteria needed to answer it. |
| Author and reviewer | Named accountable owner or the documented editorial team; do not invent credentials. |
| Evidence and primary sources | Source URLs, internal evidence-register IDs, territory and access date for every material claim. |
| Claim boundaries | What the page must not promise without new evidence, including rights, availability, catalog totals, quality, price, trial, refund or affiliation claims. |
| Update cadence | A dated review frequency and the condition that triggers an earlier review. |
| Internal links | At least two useful, contextual links and any relevant support, pricing or disclosure link. |
| CTA and conversion event | The visitor action, event name and disclosure required for it. |
| Metadata and schema | Proposed title, description, social image and only the schema types represented by visible content. |
| Accessibility and performance | Heading outline, tables/media alternatives, image dimensions and third-party dependencies to test. |
| Approval | Editor, commercial owner where applicable, review date and decision: publish, revise, noindex, merge or redirect. |

Do not publish the page or add it to the sitemap if the evidence, owner, indexability decision or claim boundaries are unknown.
