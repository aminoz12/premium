# Answer-ready page standard

Every editorial page should:

1. Answer its primary user question in the introduction.
2. State the applicable date, territory and important limitation.
3. Use descriptive headings, short explanatory paragraphs and tables only when they make a decision easier.
4. Link to primary sources, explain methodology for original research and identify the responsible editorial owner.
5. Separate editorial guidance from commercial calls to action.
6. Use structured data only for visible content that genuinely matches the schema type.

Do not produce `ai.txt`, hidden prompt text, crawler-specific variants or claims that a page will be cited by an AI system. Update pages when material sources, rights or dates change.
