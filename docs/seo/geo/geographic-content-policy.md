# Geographic content policy

- Use one canonical global domain and the existing subdirectory architecture only where a page has distinct, evidence-backed regional usefulness.
- Do not generate country, city, language, team, channel or event pages from templates alone.
- A regional page needs a specific user question, distinct source evidence, a dated territory statement, useful internal links and an editorial owner.
- Verify broadcaster, rights and replay information from official or authorized sources; availability changes by territory and time.
- Hreflang is used only for genuinely equivalent, reciprocal language or regional alternatives. A country keyword alone does not qualify.

If a regional page no longer has differentiated value, merge it into the relevant guide or redirect it to the best current canonical page.
