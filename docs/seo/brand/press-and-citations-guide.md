# Press & Citation Guidelines

This document details external citation standards, media mentions, and link building policy for **WATCHWORLDCUP**.

## 1. Citation Standards

- All technical figures (e.g. 4K streaming bandwidth requirements, device hardware specifications) must cite official manufacturer or protocol documentation.
- All match schedules and stadium locations must cite official FIFA releases.
- All replay availability claims must cite rights-holder platform support documentation.

## 2. Media Mentions & Press Outreach

When referenced by third-party media outlets or technology blogs:
- Request attribution to `WATCHWORLDCUP` linking to `https://watchworldcup.us`.
- Provide high-resolution logo assets available at `https://watchworldcup.us/logo.svg`.
- Direct technical inquiries to `support@watchworldcup.us` or WhatsApp support (`+212 723 279 328`).

## 3. External Link Hygiene

- Inspect external link validity weekly via `npm run links:check`.
- Require HTTP 200/301 responses for all outbound primary source links.
- Avoid linking to unverified third-party streaming sites or unvetted aggregators.
