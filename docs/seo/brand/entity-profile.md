# Entity and profile checklist

Before adding or changing an external profile, record the following:

| Field | Required record |
| --- | --- |
| Profile URL | Exact public URL and account handle |
| Owner | Named internal owner with account-control confirmation |
| Brand name and logo | Must match [brand identity](brand-identity.md) |
| Public contact | Must use the verified support route or be omitted |
| Description | Must follow [messaging boundaries](messaging-and-claims.md) |
| Territory / address | Add only when legally accurate and eligible for publication |
| `sameAs` decision | Add to structured data only after ownership is confirmed |
| Review date | Recheck quarterly and after any ownership change |

An online-only business must not create a business listing or address merely for local ranking. Never publish an address, phone line, staff member or review profile that cannot be verified.
