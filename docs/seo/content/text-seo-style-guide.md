# Text SEO style guide

## Write clearly

- Use the user’s question in the title, H1 or opening where natural.
- Give a direct answer first, then context, steps, limitations and sources.
- Use one clear H1, descriptive H2/H3 headings, meaningful links and readable paragraphs.
- Write unique titles and descriptions that accurately summarize the page. Do not target a universal character or word-count rule.

## Preserve trust

- Attribute factual claims to primary sources and include relevant dates and territories.
- State uncertainty and confirm-before-payment boundaries for commercial content.
- Distinguish a sourced fact, a test result and an editorial interpretation.
- Never add hidden text, keyword lists, duplicate city pages, fabricated testimonials or misleading competitor/rights-holder references.

## Links and calls to action

Link to the next useful editorial resource, support page or transparent commercial page. Use a commercial CTA only when it fits the reader’s task and disclose availability limits before payment.
