# Repository inventory

| Item | Current implementation |
| --- | --- |
| Framework/router | Next.js 16 App Router (`app/`) with TypeScript and React 19 |
| Package manager | npm (`package-lock.json`) |
| Production build | `npm run build` (`next build --webpack`) |
| Type check | `npm run lint` (`tsc --noEmit`) |
| Metadata | Route-level `metadata` objects generated by `lib/seo.ts` |
| Canonicals | `canonicalUrl()` in `lib/site.ts`; apex host and no trailing slash except origin |
| Schema | Server-rendered JSON-LD components in `app/schema.tsx` and `<OptimizedImage />` ImageObject markup |
| Robots/sitemap | `app/robots.ts`, `app/sitemap.ts` (with image sitemap entries) |
| Content/data | Typed TypeScript catalogs in `lib/`, route components, and versioned public CSV/JSON downloads |
| Content planning | `docs/seo/content-brief-template.md` is required before adding an indexable route |
| Brand SEO | Entity Knowledge Graph (`seo/brand/`), E-E-A-T policies, and `lib/brand.ts` schema tools |
| Geo SEO | Regional market mapping (`seo/geo/`), Hreflang cluster tags, `/llms.txt`, and `lib/geo.ts` |
| Image SEO | WebP social cards (`public/images/og/`), `<OptimizedImage />`, `seo/images/`, `lib/image-seo.ts`, and `npm run images:seo` |
| Technical SEO | Crawl budget policy (`seo/technical/`), CDN caching policies, and Core Web Vitals handbook |
| Analytics | No third-party analytics script currently loads; CTA interaction events stay in the browser data layer |
| Deployment | Netlify configuration (`netlify.toml`) with Node 20 (`.nvmrc`) |
| Verification | `scripts/*check.mjs`, `scripts/validate-image-seo.mjs`, `scripts/release-check.mjs`, build and production smoke checks |

The application uses no Pages Router and no separate CMS. The legacy client homepage should not add `next/head` metadata or JSON-LD; route metadata and server schema are authoritative.
