# Brand SEO & Entity Optimization Package

This directory contains the machine-readable brand architecture, entity knowledge graph definitions, reputation policies, and citation registers for **WATCHWORLDCUP**.

## Files Overview

| File | Purpose |
| --- | --- |
| `brand-entity-knowledge-graph.json` | Schema Org entity mapping, canonical identity, official contact paths, and Knowledge Graph attributes. |
| `brand-reputation-policy.json` | E-E-A-T rules, forbidden marketing claims, and mandatory disclosure requirements. |
| `citation-register.json` | Primary source audit registry and outbound/inbound link equity rules. |

## Brand Pillars

1. **Canonical Identity**: `WATCHWORLDCUP` (`https://watchworldcup.us`)
2. **Authority & E-E-A-T**: Every guide cross-references primary official sources (FIFA, FOX, Apple TV, etc.).
3. **Claim Boundaries**: Zero unverified claims regarding channel count, buffer guarantees, or official licenses.
