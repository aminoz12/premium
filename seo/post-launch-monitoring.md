# Eight-week SEO monitoring plan

Record observations weekly; do not interpret normal crawl delay as a guaranteed failure or recovery.

## Weekly metrics

- submitted sitemap URLs;
- discovered sitemap URLs;
- indexed sitemap URLs;
- pages with crawl or fetch errors;
- soft-404 reports;
- duplicate/canonical reports;
- crawled-currently-not-indexed reports;
- redirect errors and chains;
- manual actions and security issues;
- top queries, pages, countries and devices when Search Console data becomes available;
- organic sessions and qualified WhatsApp leads only when consent-aware analytics and CRM data exist.

## Escalation

- Any intended page returning non-200: immediate release investigation.
- Any unknown path returning 200: immediate soft-200 regression investigation.
- Any sitemap count other than 40 without an approved architecture change: block submission.
- Any unexpected canonical host: block release.
- Any unsupported commercial or affiliation claim: remove immediately.
- Any manual action or security issue: preserve evidence and involve the verified property owner.

Do not promise rankings, traffic, indexing, recovery or Google approval.
