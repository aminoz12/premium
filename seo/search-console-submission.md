# Search Console submission procedure

## Property

Use the verified domain property for `watchworldcup.us`. Do not create separate GEO subdomain properties for this architecture.

## Sitemap

Submit only:

```text
https://watchworldcup.us/sitemap.xml
```

Expected submitted URL count: 40.

Remove the legacy sitemap children after the rebuild is publicly verified. Do not submit feed, image-manifest, utility or download URLs as page sitemaps.

## Initial inspections

Inspect a representative set rather than requesting every URL:

1. homepage;
2. pricing;
3. order;
4. live TV;
5. legal IPTV guide;
6. setup guide;
7. 2026 archive;
8. final archive;
9. winners dataset;
10. research methodology;
11. data catalog;
12. privacy or terms page.

Confirm the selected canonical matches the declared canonical and that rendered HTML contains the visible H1 and page body.

## Migration checks

Inspect one example from each redirect family and verify the final URL:

- channels alias;
- legacy event hub;
- legacy match;
- legacy team;
- USA replay locale;
- generic locale;
- final article;
- setup article.

Do not request indexing for 404, 410, redirect, utility or download URLs.

Search Console submission does not guarantee crawling, indexing or ranking.
